## 🌟 Featured Projects

### 🌿 [Landroid](https://github.com/SilverSouls226/landroid) — AI-Driven Parcel Management & GIS Analytics
> *High-performance mobile ecosystem empowering landowners with real-time agriculture intelligence.*

- Integrated **Open-Meteo** weather dynamics and **ISRIC SoilGrids v2.0** soil telemetry APIs.

### 🤖 [TRIAD — The AI Delivery Engineer](https://github.com/SilverSouls226/triad-ai-delivery-engineer)
> *Read requirements once. Build a graph. Instantly calculate blast radius on requirement changes.*
- Built for **FRONTIER 2026** (AWS Student Builder Groups) — Agentic Systems Track.
- **FastAPI + LangGraph** backend orchestrating Analyst, Data, and Test multi-agent workflows.
- Embedded **SQLite + NetworkX** Requirement Graph engine with PageRank risk scoring and **ChromaDB** RAG/semantic caching.
- Dynamic dashboard built with **React + Vite + Tailwind CSS**.

### 💻 [ZenOS](https://github.com/SilverSouls226/ZenOS) — 64-bit Hobby Operating System
> *Minimal educational operating system built from scratch for x86_64 architecture.*
- Developed with **C** and **x86_64 Assembly** to run on bare-metal hardware.
- Engineered a freestanding GCC cross-compilation toolchain without host OS runtime dependencies.
- Multiboot2 bootloader support via GRUB, custom VGA text driver, and GDB/QEMU debugging workflow.

- Built in **C** using POSIX APIs and ANSI rendering.
- Supports regex-based focus filtering, smart word wrapping, and dynamic string parsing.
